# Obsidian Elite Simulator

Independent offline Android membership-card simulator. Not affiliated with American Express or any financial institution. All financial figures and cards are fictional. No real banking or payment functionality.

## Run
`npm install` then `npx expo start`.

## APK
Upload the project files (including `.github/workflows/android-apk.yml`) to a GitHub repository. Open **Actions > Android Debug APK > Run workflow**. Once the workflow succeeds, download the `obsidian-elite-debug-apk` artifact. This is a test/debug APK, not a production release.

Offline profiles stay on the device. Clearing app data removes the profile. Passwords are never sent online. Do not use real banking passwords.
